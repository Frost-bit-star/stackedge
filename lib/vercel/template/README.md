# Stackedge FRPS deployment

Generated by `stackedge vercel init`. Deploy this directory to Vercel.

## Configuration

`config.json` contains the deployment service ID, bearer token and app name. It is generated locally by Stackedge and is read by `api/gateway.js`.

Environment variables still override `config.json`:

- `STACKEDGE_FRPS_SERVICE_ID`
- `STACKEDGE_FRPS_TOKEN`
- `STACKEDGE_FRPS_APP`
- `STACKEDGE_FRPS_MAX_BODY_SIZE`

Keep this project private: `config.json` contains a live bearer token.

If config is missing, `server.js` stays up and returns the branded error page listing the missing service ID and token.

When the app is offline or a relay error occurs, the gateway returns the branded Stackedge error page. The page directs visitors to retry and directs owners to report issues or open pull requests at https://github.com/Frost-bit-star/stackedge.

## Redis mailbox

Vercel can route public HTTP requests to a different Function instance than the one running FRPC workers. The gateway uses a short-lived Redis mailbox for requests and results, so any instance can serve a visitor request.

Set one of these on the Vercel project:

- `REDIS_URL`
- `REDIS_CONNECTION_STRING`
- `STACKEDGE_REDIS_URL`

Upstash REST credentials are also accepted:

- `UPSTASH_REDIS_REST_URL`
- `UPSTASH_REDIS_REST_TOKEN`

`KV_REST_API_URL` and `KV_REST_API_TOKEN` are aliases. Without Redis, the gateway uses an in-memory mailbox for local development only.

Redis keys expire automatically. Shared bodies are capped at 6 MiB. FRPC workers poll `/_frpc/poll` and submit responses to `/_frpc/result`.

## Trade-offs

- Without Redis the gateway uses in-memory state: free and simple, but not reliable across Vercel instances.
- With Redis routing works across instances, but it needs a user-owned Redis database, one extra network hop, 6 MiB shared bodies, and up to a 20 second poll wait.
- WebSocket tunnels are avoided on Vercel because the socket pins to one instance and cookies do not control affinity.
- Vercel Blob is not the default because its free tier has monthly operation limits and higher latency.

## Runtime check

`api/gateway.js` exports a Node HTTP server. Fluid compute is recommended so `/_frpc/poll` can stay open for up to 20 seconds. `vercel.json` sets `maxDuration: 300`.

Run `stackedge vercel probe <app>` on the user's machine after deployment. `routing: pull-redis` means Redis is active, `routing: pull-memory` means local-only in-memory mode, and `routing: legacy` means the deployment must be redeployed.
